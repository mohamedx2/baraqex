# Baraqex Examples

This directory contains example projects demonstrating various Baraqex features.

## Examples

### [Basic App](./basic/)
A simple counter application with hooks and state management.

### [Todo App](./todo/)
A complete todo application with WASM-powered validation.

### [Full-Stack API](./fullstack/)
A full-stack example with REST API, database, and authentication.

### [SSR App](./ssr/)
Server-side rendered application with hydration.

## Running Examples

```bash
# Navigate to an example
cd examples/basic

# Install dependencies
npm install

# Start development server
npm run dev
```

## Creating Your Own

Use the CLI to scaffold new projects:

```bash
npx create-baraqex-app my-app --template basic
```
